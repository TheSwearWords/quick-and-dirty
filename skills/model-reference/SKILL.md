# Model Reference (prerequisite)

Output: `prereqs/model-reference.md`, images in `prereqs/model-reference/`. Needs: nothing.

Built once per project and shared. If the output already exists, show it and ask whether to reuse it (default) or redo it. Build any missing needs first by running their skills. Mark anything inferred as "(assumed)" and end with the questions the user needs to answer.

Collect the views (front, side, top, details) from references/ into prereqs/model-reference/. Write overall proportions or dimensions, parts and how they fit, materials and finishes, and which reference shows what. List anything the references don't show (the back, a hidden part) as questions.
