# Screen Inventory (prerequisite)

Output: `prereqs/screen-inventory.md`. Needs: nothing.

Built once per project and shared. If the output already exists, show it and ask whether to reuse it (default) or redo it. Build any missing needs first by running their skills. Mark anything inferred as "(assumed)" and end with the questions the user needs to answer.

Inputs: screenshots of the current app or a list of screens, and the kit's component list if the kit exists. For each screen: layout, how it connects to other screens, components used, the matching kit component, and anything missing. End with one gap list across all screens.
