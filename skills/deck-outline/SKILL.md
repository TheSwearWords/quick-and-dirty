# Deck Outline (prerequisite)

Output: `prereqs/deck-outline.md`. Needs: `prereqs/product-brief.md` (skill `product-brief`).

Built once per project and shared. If the output already exists, show it and ask whether to reuse it (default) or redo it. Build any missing needs first by running their skills. Mark anything inferred as "(assumed)" and end with the questions the user needs to answer.

Ask for the audience, length and purpose if they aren't given. Write the one takeaway first, then each slide: its point in one sentence, and the visual or data it needs. Note whether speaker notes are wanted.
