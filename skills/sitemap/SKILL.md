# Sitemap (prerequisite)

Output: `prereqs/sitemap.md`. Needs: `prereqs/product-brief.md` (skill `product-brief`).

Built once per project and shared. If the output already exists, show it and ask whether to reuse it (default) or redo it. Build any missing needs first by running their skills. Mark anything inferred as "(assumed)" and end with the questions the user needs to answer.

Read the product brief and any reference sites in research. For each page: its goal, then each section in order with its purpose, key message and call to action. Keep it as small as the goal allows; a launch site may be one page.
