# Product Brief (prerequisite)

Output: `prereqs/product-brief.md`. Needs: nothing.

Built once per project and shared. If the output already exists, show it and ask whether to reuse it (default) or redo it. Build any missing needs first by running their skills. Mark anything inferred as "(assumed)" and end with the questions the user needs to answer.

Read concept.md, research.md or research/*.md, and anything the user passes on. If the inputs are too thin, ask.

Cover: one-line description, audience, the problem, key features (each with its benefit), proof points, competitors and how this differs, and the one action a visitor should take.
